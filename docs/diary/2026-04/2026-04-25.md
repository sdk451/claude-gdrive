#### Autonomous-mode scaffolding + timestamp-first diary entries

Two pieces of feedback became one commit (`1cf6c50`) on
`TOK-6/s01-repo-bootstrap`:

##### 1. Diary entries lead with the timestamp
The stop-hook now emits an H2 timestamp line as the first text of every
materialised entry, with persona / branch / story dropped to a subdued
italic line directly below. Any headings inside the agent's authored
summary (`#`..`#####`) are demoted by one level so the timestamp H2 stays
unique to each entry. This very block is the first one produced under the
new format — `### Autonomous-mode scaffolding...` will land in the diary as
`#### Autonomous-mode scaffolding...` once the stop-hook runs.

##### 2. Linear sync is autonomous-loop-only
Manual commits no longer trigger Linear comments. The
`linear-sync-prompt.sh` stop-hook now requires `.cursor/autonomous-mode.txt`
to exist AND its first `[A-Z]+-[0-9]+` token to match the branch's story
id; otherwise it's silent. The marker is set/cleared by
`scripts/autonomous-start.sh <STORY_ID> [mode]` and
`scripts/autonomous-stop.sh`. The marker carries `mode` (`full` | `branch-only` | `dry-run`)
and an iso start timestamp.

The new `/autonomous` Cursor command orchestrates the full loop: pre-flight
clean tree + `gh auth`, optional pull-next-story from the Tokenomik backlog,
set issue `In Progress`, branch off `main`, hand to `/planner` and
`/test-architect`, run the implementer's TDD Ralph loop with per-commit
Linear sync, final verify (`pnpm typecheck`/`lint`/`test` + targeted suite),
push, `gh pr create --fill`, `gh pr merge --auto --squash` (CI is the gate;
no human review needed in `full` mode), advance issue to `In Review` /
`Done`, clear the marker, author a diary summary.
